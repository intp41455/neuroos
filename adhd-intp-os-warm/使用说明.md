# NeuroOS 暖系启动版 · 使用说明

> 一个为 ADHD / INTP 设计的任务拆分与启动辅助工具。数据保存在本机浏览器 localStorage 中，换设备或清缓存会丢失，请定期导出备份。

---

## 一、底部导航：4 个主 Tab

| Tab | 作用 |
| --- | --- |
| **今天** | 看当前节律阶段、推荐下一步、快速开始单步执行 |
| **任务** | 所有任务仓库，新建 / 打开 / 管理任务 |
| **记录** | 快速记录想法、停车区、睡前交接、信息蒸馏 |
| **我的** | 节律设置、洞察统计、数据导入导出 |

---

## 二、第一次打开：启动辅助

如果今天没有任何任务，首页会显示一个大大的输入框：

1. 直接输入你脑子里最想完成的一件事，例如“整理衣柜”。
2. 点**“拆成 5 步并启动”**，系统会自动识别类型并生成 5 个小步骤。
3. 也可以选 **“2 分钟版”**，先把任务压到最小可启动单位。

> 如果你连“想做什么”都写不出来，点 **“随机挑一件”**，让系统帮你从已有任务里抽一个。

---

## 三、新建任务（任务 Tab）

1. 点底部 **“任务”**。
2. 点 **“+ 新建任务”**。
3. 填写：
   - 任务标题
   - 类型（写 / 整理 / 学习 / 沟通 / 活动 / 事务 / 开发 / 习惯）
   - 优先级、预计完成日期等
4. 系统会根据类型自动拆分 5 步，你也可以手动增删改步骤。

### 任务详情里的三种视图

点任意任务卡片进入详情后，顶部有三个按钮：

| 视图 | 适合场景 |
| --- | --- |
| **网** | 思维混乱、想法乱窜时，用网状节点自由拖拽归类 |
| **树** | 已经理清层级，用树状结构看“父子”关系 |
| **线** | 进入执行态，把节点按执行顺序排成一条线 |

在**网**视图里双击空白处新建节点，拖动节点到不同抽屉分类。点节点可编辑标题。把节点拖到**“生成执行线”**区域，系统会按顺序生成执行步骤。

---

## 四、单步执行模式（今天 Tab / 任务详情）

目的是降低启动阻力：一次只看一步。

1. 在 **今天** Tab 里，系统会推荐“下一步”。
2. 点 **“开始只做这一步”** 进入单步界面。
3. 界面上只有三个按钮：
   - **完成** → 标记这一步做完，并自动推荐下一步
   - **跳过** → 这一步先不做
   - **退出** → 回到主界面

> 没有倒计时，没有番茄钟。完成时间会被静默记录，用于后续统计校准。

## 五、记录 Tab：4 个功能区

### 1. 快速记录
脑子里的念头、待办、担忧、灵感，先丢进去，不占工作记忆。

### 2. 停车区
把暂时做不了的事分类存放：
- **洞察**、**问题**、**卡点**、**灵感**、**引用**

后面处理任务时可以从停车区拖出来用。

### 3. 睡前交接（3-2-1）
每天睡前填写：
- **3 个重点**：今天记住了什么
- **2 个假设**：明天想验证什么
- **1 个明早第一步**：降低明天启动阻力

填完点**“保存交接”**，明早打开会自动显示。

### 4. 信息蒸馏
把大量碎片信息压缩成可用结论：
1. **侦察**：列出关键事实
2. **重构**：归类成组
3. **分层**：提取要点和论据
4. **校验**：问自己“这结论可靠吗？”

## 六、我的 Tab：节律、统计、备份

### 节律设置
设置你的：
- 起床时间
- 上线时间（开始工作）
- 断电时间（停止接收新任务）
- 入睡时间

系统会根据时间反推当前处于哪个阶段：睡眠期 / 校准期 / 深度期 / 创意期 / 断电期，并在首页顶部提示。

### 洞察统计
- 预估时间 vs 实际时间校准系数
- 近 7 天完成柱状图
- 连续启动天数 streak
- 累计专注时长

### 数据备份
- **导出 JSON**：把全部数据下载到本地
- **导入 JSON**：从本地文件恢复数据
- **清空数据**：一键重置

> **强烈建议每周至少导出一次备份。**

## 七、一些小技巧

| 场景 | 做法 |
| --- | --- |
| 不知道先做什么 | 用 **今天** Tab 的“推荐下一步”或“随机挑一件” |
| 任务太大 | 点任务详情 → 网视图 → 拆成多个节点 → 生成执行线 |
| 启动困难 | 用 **2 分钟版**，只做 2 分钟，做完再决定 |
| 脑子很乱 | 先去 **记录** → 快速记录 / 停车区 清空大脑 |
| 睡前焦虑 | 填写 **3-2-1 交接**，把焦虑交给明天的自己 |

---

## 八、数据与隐私

- 所有数据保存在**本机浏览器**中。
- 不登录、不上传云端、不跨设备同步。
- 换手机 / 清缓存 / 卸载浏览器会导致数据丢失，请主动导出备份。
